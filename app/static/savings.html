How the numbers are made

  • Prices and routing come from CaveDawg's own settings (app/config.py), the same ones the proxy bills and routes with. Cached input is priced at the cache-read rate.
  • A prompt keeps one model for all of its tool rounds. Calls CaveDawg doesn't judge stay on Opus.
  • A stuck agent is assumed to burn 20 calls before anyone notices; CaveDawg stops it after 3.
  • Budgets cap the worst case rather than lower the average, so they add nothing to these figures.
  • This is an estimate for the team described in step 1, not a bill. The task mix and token sizes move the result the most.
